# 設計交接包驗證紀錄

日期：2026-10-18。驗證對象為交接文件與介面參考，不是正式應用或 NAS 服務。

## 文件驗證

- 使用 Node.js 執行 `node scripts/build-design-handoff.mjs`，由八個來源章節建立 DESIGN_DEVELOPMENT.md。
- 使用 `node scripts/verify-design-handoff.mjs` 檢查 Markdown 標題、UTF-8 替代字元、程式區塊配對、本機連結、必要檔案及核心需求關鍵字。
- 彙整檔涵蓋使用者開發規則、產品、UI、資料／API、部署、測試、現況與 Claude 指令。關鍵字檢查只是防漏檢查，不是功能測試。
- 完整封裝以 DELIVERY_MANIFEST.json 列出每個交付檔的 byte 數與 SHA256，ZIP 封裝後再比對內部檔案與雜湊；ZIP 自身雜湊另存於同目錄 .sha256 檔。
